# 10-K risk-topic gold labels

`risk_topic_sample.jsonl` (generated by `scripts/prepare_10k_gold_sample.py`) is a stratified
sample of ~10 paragraphs per (ticker, section) from Project 1's raw, untagged 10-K paragraphs.
Project 1's own Jev tags can't be used as gold for evaluating Jev, so these need a human label.

## How to label

For each row, fill in `"label"` with exactly one of:

- `liquidity`
- `credit`
- `regulatory`
- `cyber`
- `macro`
- `competition`
- `operations`
- `legal`
- `supply_chain`
- `labor`
- `other`

Pick whichever topic the paragraph *primarily* discusses (same question Jev is asked in
Project 1 -- see `report_qa/tagging/tagger.py`'s `TOPIC_QUESTION`). Use `other` if nothing
else fits; don't leave `label` blank -- `harness.data.risk_topics.load()` raises if any row
still is.
