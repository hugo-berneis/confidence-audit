Pros & Cons by Approach

Jev

TypeSafe System One (src/harness/models/decision_jev.py)
Pros
  • Returns a confidence natively with every decision, no prompting required
  • Structurally bounded to the given option list; can never answer outside it
  • Fast: a single real smoke-test call returned in ~0.2s
  • Already used in Project 1 to gate retrieval and answer display
Cons
  • Weak at numbers, counting, and literal detail by design (Project 1's own finding)
  • Only bounded judgments, no open-ended writing
  • Real calibration on this harness's tasks is still unmeasured end to end
Best fit

High-volume bounded decisions already embedded in app logic: the risk-topic tagging, relevance filtering, and groundedness gates Project 1 already runs on every paragraph.

LLM (Claude Haiku 4.5)

Verbalized confidence (src/harness/models/llm_client.py)
Pros
  • Flexible: the same client answers any classification task via prompting
  • Can be prompted to justify an answer, not just emit a bare label
  • No fixed option-list infrastructure needed to stand up a new task
Cons
  • Confidence is self-reported, not trained against a scoring rule: not the same thing as a calibrated probability (documented limitation, see REPORT.md)
  • Slower and costlier per call than Jev at volume
  • Needs a parser for its JSON output; a malformed response is a retryable failure
Best fit

Tasks where a fixed option list doesn't fit, or as an independent second opinion to sanity-check Jev's decisions on the same input.

Status: Mock-Validated, Real Results Pending

The pipeline runs end to end and the numbers below are real output from this repo, but both clients return a constant confidence by design (0.6 for the mock Jev, 0.7 for the mock LLM), so nothing here is a real calibration finding yet. AUROC lands on exactly 0.500 for both: the mathematical signature of a score with no variation to rank by. The real JevDecisionClient is already wired up and smoke-tested: a single real call against each task returned a sensible, varying answer in well under a second, so what remains is a full real run, plus hand-labeling the 10-K gold sample before that task has any gold labels at all.
